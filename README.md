# Closet Intake Lab

옷 추천 서비스의 전 단계인 `옷장 등록`만 검증하는 브라우저 프로토타입입니다.

## 실행

화면만 보려면 `index.html`을 브라우저에서 열면 됩니다.

`원본 상품 정보 가져오기`까지 테스트하려면 Node 18 이상에서 서버로 실행해야 합니다.

```bash
npm start
```

Windows에서 Node가 PATH에 없으면 아래 파일을 PowerShell로 실행해도 됩니다.

```powershell
.\run-local.ps1
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8787
```

## 테스트 흐름

1. `주문내역` 탭에서 스크린샷을 업로드합니다.
2. `OCR 실행 후 상품 정리`를 눌러 주문내역 텍스트를 상품 단위로 묶습니다.
3. 자동 정리가 어긋나면 OCR 원문을 수정하고 `OCR 원문에서 상품 후보 다시 정리`를 누릅니다.
4. 후보 카드에서 상품명, 브랜드, 옵션, 가격, 분류, 색상, 무드를 수정합니다.
5. `원본 상품 정보 가져오기`는 서버로 실행했을 때 무신사 상품 후보를 찾아 이미지/현재 가격/상품 URL을 가져옵니다.
6. `맞아요, 등록`을 누르면 옷장에 저장됩니다.
7. 주문내역에 없는 옷은 `직접 사진` 탭에서 사진과 정보를 넣어 등록합니다.
8. 등록된 옷장은 브라우저 localStorage에 저장되며, `JSON 내보내기`로 백업할 수 있습니다.

## 현재 한계

- OCR은 Tesseract.js CDN을 사용합니다. 인터넷이 안 되면 OCR 버튼은 동작하지 않을 수 있습니다.
- `file://index.html`로 열면 상품 조회 서버가 없어서 원본 상품 정보 가져오기가 동작하지 않습니다.
- 현재 서버는 무료 실험용으로 DuckDuckGo 검색 결과에서 무신사 상품 페이지를 찾아 메타데이터를 읽습니다.
- 검색 결과 페이지 구조나 무신사 차단 정책에 따라 실패할 수 있습니다.
- 안정적인 서비스로 가려면 네이버 쇼핑 API, Google Custom Search API, 또는 사이트별 정식 API/제휴 방식을 검토해야 합니다.
