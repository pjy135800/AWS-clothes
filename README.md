# Closet Intake Lab

옷 추천 서비스의 전 단계인 `옷장 등록`과 날씨/컨셉 기반 상하의 추천을 검증하는 브라우저 프로토타입입니다.

## 실행

화면만 보려면 `index.html`을 브라우저에서 열면 됩니다.

`원본 상품 정보 가져오기`까지 테스트하려면 Node 18 이상에서 서버로 실행해야 합니다.

```bash
npm start
```

Windows에서 Node가 PATH에 없으면 아래 파일을 PowerShell로 실행해도 됩니다.

```powershell
.\run-local.ps1
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8787
```

## 테스트 흐름

1. `OCR` 탭에서 주문내역 스크린샷을 업로드합니다.
2. `OCR 실행 후 상품 정리`를 눌러 주문내역 텍스트를 상품 단위로 묶습니다.
3. 자동 정리가 어긋나면 OCR 원문을 수정하고 `OCR 원문에서 상품 후보 다시 정리`를 누릅니다.
4. 후보 카드에서 상품명, 브랜드, 옵션, 가격, 분류, 색상, 무드를 수정합니다.
5. `원본 상품 정보 가져오기`는 서버로 실행했을 때 무신사 상품 후보를 찾아 이미지/현재 가격/상품 URL을 가져옵니다.
6. `맞아요, 등록`을 누르면 옷장에 저장됩니다.
7. OCR이 놓친 상품은 `직접 검색` 탭에서 브랜드와 제품명만 넣어 후보를 검색합니다.
8. 상품 URL을 알고 있으면 `URL` 탭에서 URL만 넣어 상품 정보를 가져옵니다. 무신사가 가장 안정적이며, 다른 쇼핑몰은 공개 메타데이터가 있으면 시도합니다.
9. 주문내역에 없는 옷은 `직접 사진` 탭에서 사진과 정보를 넣어 등록합니다.
10. `오늘 코디 추천`에서 지역과 컨셉을 고르면 현재 날씨를 참고해 등록된 상의/하의 조합 2개를 추천합니다.
11. 등록된 옷장은 브라우저 localStorage에 저장되며, `JSON 내보내기`로 백업할 수 있습니다.

## 현재 한계

- OCR은 Tesseract.js CDN을 사용합니다. 인터넷이 안 되면 OCR 버튼은 동작하지 않을 수 있습니다.
- `file://index.html`로 열면 상품 조회 서버가 없어서 원본 상품 정보 가져오기가 동작하지 않습니다.
- 현재 서버는 무신사 검색 API를 먼저 시도하고, 실패하면 무료 웹 검색으로 후보 URL을 찾습니다.
- ZARA/기타 쇼핑몰은 URL 등록으로만 보조 실험합니다. 사이트가 Open Graph, Twitter Card, JSON-LD, Next.js 데이터 같은 공개 상품 메타데이터를 제공하면 이미지/상품명/가격을 가져올 수 있습니다.
- 봇 차단, 로그인 필수 페이지, 앱 전용 주문내역은 서버에서 상품 이미지를 가져오지 못할 수 있습니다.
- 날씨는 Open-Meteo 무료 API를 사용합니다. 연결 실패 시 기본 날씨값으로 추천합니다.
- 현재 코디 참고 후보는 공개 Pinterest 검색을 짧게 시도하고, 실패하면 준비된 스타일 이미지로 바로 대체합니다.
- 추천 점수는 계절감/컨셉/색 조합에 더해, 옷 이미지에서 추출한 밝기/채도/색감 계열이 참고 코디 이미지와 가까운지도 반영합니다.
- 외부 상품 이미지는 사이트 CORS나 차단 정책 때문에 픽셀 분석이 실패할 수 있으며, 이 경우 제품명/색상 텍스트 기반 프로필로 대체합니다.
- 검색 결과 페이지 구조나 무신사 차단 정책에 따라 실패할 수 있습니다.
- 안정적인 서비스로 가려면 네이버 쇼핑 API, Google Custom Search API, Pinterest API/이미지 검색 API, 또는 사이트별 정식 API/제휴 방식을 검토해야 합니다.
